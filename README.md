# Insurance Knowledge Website

เว็บไซต์ตัวอย่างให้ความรู้เกี่ยวกับประกันชีวิตและสุขภาพ พัฒนาต่อจาก `index.html` ที่ได้รับ

## เปิดใช้งาน

1. เปิดโฟลเดอร์นี้ด้วย VS Code
2. ใช้ส่วนขยาย Live Server หรือรันเว็บเซิร์ฟเวอร์ในโฟลเดอร์
3. เปิด `index.html`

ตัวอย่างคำสั่ง:

```bash
python -m http.server 8000
```

แล้วเปิด `http://localhost:8000`

## โครงสร้าง

- `index.html` หน้าแรก
- `css/style.css` รูปแบบทุกหน้า
- `js/main.js` เมนูมือถือ FAQ ตัวแทนภาพ และตรวจแบบฟอร์ม
- `products/` หน้าความรู้ของแบบประกัน 6 ประเภท
- `articles/` บทความ 3 เรื่อง
- `articles.html` หน้ารวมบทความ
- `privacy.html` และ `terms.html` ข้อความตัวอย่างที่ต้องปรับก่อนใช้จริง
- `images/README.txt` รายการชื่อไฟล์ภาพและคำอธิบายภาพที่ควรสร้าง

## หมายเหตุสำคัญ

- แบบฟอร์มเป็น Front-end เท่านั้น ยังไม่ส่งข้อมูลไปเซิร์ฟเวอร์หรืออีเมล
- ก่อนเผยแพร่จริง ควรเชื่อมระบบหลังบ้าน ปรับนโยบายความเป็นส่วนตัว และตรวจข้อมูลผลิตภัณฑ์กับเอกสารล่าสุด
- เมื่อยังไม่มีไฟล์ภาพ JavaScript จะแสดงข้อความจาก `alt` เป็นพื้นที่ตัวอย่างแทนภาพ

# Insurance Knowledge Website

เว็บไซต์ตัวอย่างสำหรับให้ความรู้เกี่ยวกับประกันชีวิตและประกันสุขภาพ  
พร้อมระบบรับข้อมูลผู้สนใจและหน้าจัดการข้อมูลเบื้องต้นสำหรับผู้ดูแล

โปรเจกต์นี้เป็น **AI-Assisted Personal Project** ที่ผมใช้เพื่อฝึกการพัฒนาเว็บไซต์
และเรียนรู้ว่าระบบ Web Application มีส่วนประกอบและการทำงานร่วมกันอย่างไร

## ✨ Features

### Public Website

- หน้าให้ความรู้เกี่ยวกับประกัน
- หน้าผลิตภัณฑ์ประกันหลายประเภท
- บทความให้ความรู้
- Responsive Layout
- แบบฟอร์มสำหรับผู้สนใจให้ติดต่อกลับ
- Privacy Policy และ Terms

### Lead Form

ผู้ใช้งานสามารถกรอกข้อมูล เช่น

- ชื่อ
- เบอร์โทรศัพท์
- อีเมล
- LINE ID
- ประเภทประกันที่สนใจ
- ช่องทางที่สะดวกให้ติดต่อกลับ
- รายละเอียดเพิ่มเติม

ระบบจะตรวจสอบข้อมูลก่อนบันทึกลงฐานข้อมูล

### Admin

มีหน้า Admin สำหรับ:

- ดูข้อมูลผู้สนใจ
- กรองข้อมูลตามสถานะ
- เปลี่ยนสถานะ Lead
- เพิ่มบันทึกของผู้ดูแล
- ลบข้อมูล
- Export ข้อมูลเป็น CSV

### Backend

Backend ใช้ Node.js และมีส่วนประกอบ เช่น

- HTTP Server
- Environment Variables
- SQLite Database
- API สำหรับรับและจัดการข้อมูล
- Input Validation
- Rate Limiting สำหรับแบบฟอร์ม
- Basic Authentication สำหรับหน้า Admin
- Security Headers
- Optional Webhook

## 🤖 How I Used AI

AI ถูกใช้เป็น Development Assistant ในหลายส่วน เช่น

- ช่วยสร้างโครงสร้างโปรเจกต์
- ช่วยเขียน JavaScript
- ช่วยสร้าง Backend
- ช่วยสร้าง API
- ช่วยออกแบบ SQLite Database
- ช่วยตรวจสอบและแก้ Bug
- ช่วยเสนอวิธีปรับปรุง Security
- ช่วยอธิบายโค้ดที่ผมยังไม่เข้าใจ

Workflow ที่ผมใช้โดยทั่วไปคือ:

```text
Idea / Requirement
       ↓
Explain requirement to AI
       ↓
AI generates / modifies code
       ↓
Run and test
       ↓
Find problems
       ↓
Describe the problem to AI
       ↓
Review and test again
       ↓
Iterate
